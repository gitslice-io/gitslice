# Storefront

A small TypeScript storefront used to demo many agents working on one
codebase at once with Gitslice and Cloudflare Artifacts.

- `src/catalog`: products, search and pricing.
- `src/cart`: the cart and its totals.
- `src/checkout`: the order flow and payment capture.
- `src/i18n`: UI strings, one file per locale.
- `src/ui`: view components.

Run the tests with `node --test test/`.
